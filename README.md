# IPS AOD

A responsive, interactive browser prototype of an always-on display dashboard, built for IPS screens.

## Run it

Open `index.html` in a modern browser. No build tools or dependencies are required.

## Features

- Live clock with digital, minimal, and seconds styles
- Date, sample weather, notification, and battery widgets
- Accent colors and adjustable brightness simulation
- Optional night dimming and fullscreen preview
- Preferences saved in the browser with `localStorage`

> This is a web preview, not a native Android always-on display service. Browsers cannot keep a screen awake or control device-level display/power settings reliably. Native Android support would require an Android project and appropriate platform APIs/permissions.
